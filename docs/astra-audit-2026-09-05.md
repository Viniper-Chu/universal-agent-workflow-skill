# GPT-6 Astra 工作流审查与取舍

审查范围：用户提供的 AGENTS 规则、RTK 使用说明，以及本仓库
`universal-agent-workflow` 0.2.0 的入口、运行政策和安装契约。
新入口是 `packages/astra-workflow` 0.1.0。

## 结论

保留具体的用户偏好与会影响结果的操作边界，把重复的通用要求和只适合
复杂协作的机制移出日常入口。Astra 的能力不是省略结果验证的理由。
新 skill 不绑定模型 API，不修改模型设置，也不承诺固定的 token 节省比例。

| 原要求或机制 | 决定 | 新版处理 |
|---|---|---|
| 临时文件不得散落 | 保留、缩短 | 使用已有输出目录，否则放 codex；不用时不创建目录 |
| 固定四类中文子目录 | 按需 | 放 Windows 参考页，不要求每个任务生成四类文件 |
| 最终文件按用户位置交付 | 保留 | 与中间文件区分 |
| 不随意动安装目录、依赖、数据、密钥、会话 | 保留 | 根据当前任务授权及真实引用关系判断，不形成无条件禁止修复 |
| Browser / Chrome 优先 | 保留目的、放宽顺序 | 按已有登录态和所需能力选工具，已有明确授权不重复问 |
| Chrome 写死本机路径 | 从公共版本删除 | 本机发现路径；个人特殊路径留在自己的项目配置 |
| 支持的高输出外部命令优先 RTK | 改为可选 | 仅用于已安装且能减少无关输出的命令；诊断需要时读原始输出 |
| 不是安全攻防项目，不要过度防御 | 改写 | 验证随影响范围增长；删除真实数据仍需检查，不能以项目小为由省略 |
| 禁止所有哈希和 SHA256 | 删除一刀切禁令 | 不例行生成；发布校验、精确重复识别等真实需求可以使用 |
| 不要反复测几乎不可能的情况 | 保留目的 | 聚焦实际行为与合理边界；测试后无新问题就交付 |
| rubric 不要机械化 | 保留目的 | 无需每次评分表；只在真实比较或验收需求下使用 |
| 所有项目必须建 Git，文件任务也一样 | 放宽 | 长期维护项目沿用 Git；一次系统排查不用建库 |
| 只留本次和上次，其余删除 | 限定对象 | 只适用于已授权清理、可确认归属的生成物；不清 Git 历史与唯一成果 |
| 每次角色识别、完整合同、固定三层协作 | 从默认流程删除 | 普通任务直接完成；复杂任务用短计划，独立工作才委派 |
| 每次迁移都再问一遍确认 | 改为授权判断 | 已明确要求的同范围交接直接准备和执行；扩大范围才需补充授权 |
| 全能力探测、固定版本 bootstrap、双回执 | 仅保留旧引擎模式 | 新版普通工作无需初始化；既有合同不自动绕过 |
| epoch、报告修订、独立身份验收 | 仅保留旧引擎模式 | 有合同的管理任务继续执行；简单修复不强制生成这些记录 |
| 无真实工具却宣称已交接、已完成 | 继续禁止 | 根据工具返回区分发送、执行和完成 |
| 修复根因与恢复数据分别验证 | 保留目的 | 只有存在数据恢复时才检查两者，不要求每次填固定 JSON |
| 旧规则每一行必须存结构化迁移胶囊 | 从默认流程删除 | Git 中的旧版本足够留痕；不将个人历史材料打包公开 |
| 任务后自动清理、源会话移除 | 不作为默认行为 | 当前请求授权的清理可执行；不能因任务完成就清理用户会话 |

## 文件及版本关系

- `astra-workflow/SKILL.md` 是日常入口；文件操作及交接各有一份按需参考。
- `examples/AGENTS.minimal.md` 是中文项目模板，不要求与 skill 全文重复加载。
- 原 `universal-agent-workflow` 0.2.0 代码、契约和收据格式保持不变。
  仓库根 VERSION 和 Python 项目版本仍表示旧引擎版本；Astra 包独立为 0.1.0。
- 本次删减的是新工作流的默认约束，不销毁旧引擎或正在运行项目的证据。
- 不自动改写其他项目的 AGENTS.md，不重置管理层会话，不清理其他软件文件。

## 检查范围与限制

发布检查包括 skill 结构、引用链接、示例安装路径及旧引擎回归测试。
并用普通编辑、已授权发布、部分失败、文件清理、跨会话续作、既有受管任务
六类情境进行规则走查；这是人工语义审查，不是六次独立模型实测。
没有进行同任务 A/B 模型实验，因此不宣称准确率提高或总 token 成本降低了多少。

## 官方依据

OpenAI 的 [GPT-6 Astra 提示指导](https://developers.openai.com/api/docs/guides/latest-model#prompting-best-practices)
建议审查会影响行为的 skills 和 AGENTS 文件、延续已授权工作，并按改动范围安排验证。
本仓库的简化方案是作者据此作出的工程选择，不是 OpenAI 官方提供或认证的 skill。
